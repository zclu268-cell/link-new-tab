# 隐私与权限说明

适用于「链接新开」1.1.0。以下说明对应本仓库提供的扩展源码。

## 数据处理

扩展不包含服务器、统计分析、广告 SDK 或远程代码，不将网页内容、浏览记录、视频内容或设置上传到外部服务。

为执行用户点击，内容脚本会在当前网页内识别链接目标，并将目标网址发送给本机运行的扩展后台创建新标签页。扩展不会将这些网址记录为浏览历史；Chrome 和目标网站自身的记录行为由各自控制。

视频小窗使用浏览器原生 Picture-in-Picture API。扩展只识别 `<video>` 元素和播放状态，不下载、录制或上传视频。视频仍由原网站加载与播放。

## 本地保存的内容

`chrome.storage.local` 仅保存以下设置，不使用 Chrome 同步存储：

| 字段 | 内容 |
| --- | --- |
| `enabled` | 是否开启链接新开 |
| `active` | 新标签页打开后是否自动切换 |
| `excludedHosts` | 不启用链接新开的域名列表 |

这些数据不包含账号凭据、页面正文或已点击网址列表。卸载扩展会移除其本地存储；重新安装后使用默认设置。

## 权限用途

| 权限或访问范围 | 用途 |
| --- | --- |
| `storage` | 保存和读取本机开关与网站例外 |
| `activeTab` | 用户点击扩展图标时识别当前标签页及域名 |
| `http://*/*`、`https://*/*` 内容脚本 | 在普通网页中识别链接点击、阻止当前页面被链接替换，以及发现视频和显示小窗按钮 |

内容脚本会尝试运行在匹配的页面和框架中，因此 Chrome 可能显示可读取和更改网站数据的访问提示。这是上述功能的网页访问范围。网站和浏览器的权限限制仍然生效。

扩展没有申请读取完整浏览历史、管理下载、访问摄像头或麦克风的权限。创建新标签页使用 Tabs API，不申请额外的 `tabs` 权限。

## 用户控制

- 在扩展面板中可以全局关闭链接新开，或仅排除当前域名。
- 视频小窗仅在用户直接点击网页上的按钮后启动，不会自动弹出。
- 可在 Chrome 扩展管理页调整网站访问范围、停用或卸载扩展。
- 在 GitHub 提交问题或测试结果前，请自行删去个人网页地址、账号信息和截图中的隐私内容。

开发测试依赖与可选 YouTube 实测不是扩展运行代码。安装 npm 依赖、下载测试浏览器、访问 YouTube 会产生对应的网络访问；不会随扩展安装包执行。
