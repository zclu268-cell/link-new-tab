## 性能对比

使用 CDP 在真实扩展的 isolated world 包装原生 DOM 方法计数，页面自身的同名调用不计入。相同的新版 manifest 下，只替换为 v1.1.0 的 video.js 进行基线采样，以隔离算法变化。固定尺寸动态区域旁有 12000 个静态节点，进行 12 轮更新；滚动场景包含 3 个视频与 60 帧实际滚动。

| 场景与扩展操作次数 | 旧视频脚本 | 1.1.1 |
| --- | ---: | ---: |
| 无视频区域更新：整页视频查询 | 12 | 0 |
| 视频旁无关区域更新：整页视频查询 | 12 | 0 |
| 视频旁无关区域更新：视频位置读取 | 36 | 0 |
| 三视频滚动：视频位置读取 | 295 | 16 |
| 滚动停止后：视频位置读取 | 0 | 0 |

这些计数对应一次本地受控测试，不能直接换算为真实网站加载速度提升。页面真实尺寸变化仍会触发必要的按钮定位；新增含视频的子树仍会被检查。正式回归断言操作次数和停止条件，不使用依赖机器速度的墙钟阈值。
